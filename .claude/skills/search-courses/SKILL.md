# search-courses — 搜索课程视频

## 触发条件

用户说「搜索课程」「找视频」「补充课程链接」时触发。

## 工作流

### 第一步：确定搜索范围

1. 读取 `data/wiki/` 目录下所有 `.md` 文件
2. 解析每个文件的 frontmatter，提取 `title`、`tags`、`subject`
3. 可选筛选：用户可指定学科（地理/生物）或具体章节缩小范围
4. 列出待搜索的知识点清单，告知用户搜索范围

### 第二步：逐知识点搜索课程

对每个知识点执行以下流程：

**a. 构建搜索关键词**

根据知识点信息组合搜索词：
- 基础格式：`"八年级{学科}" + 知识点名称 + "讲解"`
- 复习格式：`"八年级{学科}" + 知识点名称 + "会考复习"`
- 示例：`"八年级地理 气候类型 判读 讲解"`

学科映射：
- `subject: "geography"` → 使用「地理」
- `subject: "biology"` → 使用「生物」

**b. 执行搜索**

使用 `web_search` 工具搜索以下平台：
- **B 站**（bilibili.com）：主要搜索目标，教学视频丰富
- **小红书**（xiaohongshu.com）：补充搜索，笔记形式的知识总结

搜索策略：
- 每个知识点搜索 2-3 组关键词
- 限定域名搜索：`site:bilibili.com` 或 `site:xiaohongshu.com`

**c. 筛选高质量视频**

从搜索结果中筛选，优先级排序标准：
1. **播放量**：优先选择播放量高的视频（表明内容质量好）
2. **时长**：优先选择 5-20 分钟的视频（讲解充分又不冗长）
3. **标题关键词**：优先标题中包含「讲解」「复习」「会考」的内容
4. **发布时间**：优先近 2 年内发布的内容（与当前教材版本更匹配）

每个知识点最多保留 3 个优质课程链接。

**d. 追加到 Wiki 页面**

将筛选后的课程链接追加到对应 Wiki 页面：

```markdown
## 相关课程

- [视频标题](视频URL) — 来源平台，时长（如有）
  > 简要说明该视频的覆盖内容
```

重要：采用**追加策略**，只在不存在的链接后追加，不覆盖已有内容。如果 Wiki 页面中已有「相关课程」章节，在末尾追加新链接；如果没有，创建该章节。

### 第三步：汇报结果

搜索完成后输出统计：
- 为 X 个知识点补充了 Y 个课程链接
- 按平台分组列出链接数量（B站 N 个，小红书 M 个）
- 列出未找到合适视频的知识点（如有）

## 规则

1. **不覆盖已有链接**：Wiki 页面中已有的课程链接保持不变，只追加新的
2. **质量优先于数量**：宁缺毋滥，不确定质量的链接不收录
3. **平台限定**：只搜索 B 站和小红书，不搜索其他平台
4. **链接有效性**：尽量使用完整的视频链接，避免搜索结果页链接
5. **尊重版权**：只收录公开发布的教学视频，不收录付费盗版资源
6. **批量处理**：如果待搜索知识点超过 10 个，提示用户确认是否全部处理
7. **失败容忍**：某个知识点搜索失败不影响其他知识点，记录失败原因继续执行
8. **中文搜索**：所有搜索关键词和结果描述使用中文
