# generate-practice — 生成练习题

## 触发条件

用户说「出题」「生成练习」「出几道类似的题」时触发。

## 工作流

### 第一步：读取未掌握错题

1. 扫描 `data/mistakes/` 目录下所有 JSON 文件
2. 筛选 `is_mastered === false` 的记录
3. 可选筛选：用户可指定学科（地理/生物）或章节缩小范围
4. 如果没有未掌握的错题，提示「所有错题已掌握，无需生成练习」并结束

### 第二步：读取原始题目分析

对每道未掌握的错题：

1. 读取 `data/mistakes/{id}.json` 获取关联的题目 ID
2. 读取对应的 `data/questions/{question_id}/meta.json`
3. 提取关键信息：
   - `question_type`：题型
   - `analysis.key_concept`：核心知识点
   - `analysis.answer`：正确答案
   - `analysis.explanation`：解析
   - `subject`：学科
   - `difficulty`：难度

### 第三步：生成练习题

对每道错题，基于相同知识点生成 2-3 道类似练习题：

**变换策略**（确保不是简单重复）：

- **换数据**：更改题目中的具体数值、地点、物种等
  - 地理：换一个城市的气候数据、换一个地形区域
  - 生物：换一个生物样本、换一个实验数据
- **换场景**：改变问题背景但考查相同知识点
  - 地理：从中国地理换成世界地理，从自然地理换成人文地理
  - 生物：从人体换成植物，从微观换成宏观
- **换问法**：改变提问角度
  - 正向提问 → 反向提问（「以下哪项正确」→「以下哪项错误」）
  - 原因题 → 结果题
  - 识别题 → 解释题

**题型保持**：
- 原题是选择题 → 练习题也是选择题（4 个选项）
- 原题是填空题 → 练习题也是填空题
- 原题是简答题 → 练习题可以是简答题或选择题（降低难度）

**每道练习题结构**：

```json
{
  "id": "practice_{timestamp}_{index}",
  "source_question_id": "原题ID",
  "question_type": "选择题",
  "subject": "geography",
  "difficulty": 2,
  "knowledge_points": ["知识点1", "知识点2"],
  "question_text": "题目文字",
  "options": {
    "A": "选项A",
    "B": "选项B",
    "C": "选项C",
    "D": "选项D"
  },
  "correct_answer": "B",
  "explanation": "解析文字",
  "variation_method": "换数据/换场景/换问法",
  "created_at": "ISO 8601 时间戳"
}
```

### 第四步：写入文件

1. 将所有生成的练习题写入 `data/practice/{timestamp}.json`
   - `timestamp` 格式：`YYYYMMDD_HHmmss`
   - 文件内容为 JSON 数组，包含本次生成的所有练习题
2. 如果 `data/practice/` 目录不存在，先创建目录

### 第五步：汇报结果

生成完成后输出统计：
- 生成了 X 道练习题
- 覆盖 Y 个知识点
- 按学科和题型分组列出数量
- 列出生成的文件路径

## 规则

1. **题目质量**：生成的练习题必须考查与原题相同的知识点，不能偏离
2. **难度适中**：练习题难度与原题相当或略低，不应更难
3. **答案准确**：确保生成的正确答案和解析准确无误
4. **不重复**：同一批练习题中不能出现高度相似的题目
5. **学科匹配**：地理错题只生成地理练习题，生物错题只生成生物练习题
6. **解析要求**：每道练习题必须有完整的解析，不能只有答案
7. **批量限制**：每次最多生成 30 道练习题（对应约 10-15 道错题），避免质量下降
8. **中文输出**：所有题目和解析内容使用中文
