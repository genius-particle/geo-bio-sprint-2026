# import-knowledge — 批量导入知识点

## 触发条件

用户说「导入知识点」「初始化知识库」时触发。

## 工作流

### 第一步：读取章节结构

1. 读取 `data/chapters.json` 文件
2. 解析章节和知识点的层级结构
3. 验证数据格式完整性（必须有 subject、chapter、topics 字段）

`chapters.json` 预期结构：

```json
{
  "geography": [
    {
      "chapter": "第一章 中国的疆域与人口",
      "topics": [
        "中国的地理位置",
        "中国的行政区划",
        "中国的人口分布"
      ]
    }
  ],
  "biology": [
    {
      "chapter": "第一章 生物圈",
      "topics": [
        "生物的特征",
        "生物圈的范围",
        "生物与环境的相互影响"
      ]
    }
  ]
}
```

### 第二步：创建 Wiki 页面

为每个知识点创建 Wiki 页面文件：

**a. 确定 Wiki 文件名**

- 格式：`{学科}-{章节号}-{知识点序号}-{知识点简称}.md`
- 示例：`geo-01-01-中国的地理位置.md`、`bio-01-01-生物的特征.md`
- 文件名使用中文，便于识别
- 学科前缀：`geo`（地理）、`bio`（生物）

**b. 创建页面骨架**

每个 Wiki 页面包含以下结构（与 analyze 技能的模板统一）：

```markdown
---
title: "知识点名称"
tags: [标签1, 标签2, 标签3]
created: "创建时间（ISO 8601）"
updated: "创建时间（ISO 8601）"
sources: []
links: []
category: knowledge
confidence: medium
schemaVersion: 1
subject: geography/biology
chapter: "所属章节名称"
---

# 知识点名称

## 核心知识

<!-- 待 AI 填充：该知识点的核心概念、因果关系、关键术语 -->

## 易混辨析

<!-- 待 AI 填充：容易混淆的概念对比、学生常见错误 -->

## 考试技巧

<!-- 待 AI 填充：按题型的读图/审题/答题要点 -->

## 相关知识点

<!-- 待 AI 填充：用 [[知识点名]] 链接关联的其他 wiki 页面 -->

## 例题

<!-- 自动关联：analyze 技能分析错题时自动补充 -->

## 相关课程

<!-- 自动关联：search-courses 技能搜索课程时自动补充 -->
```

字段说明：
- `核心知识`：该知识点的核心概念和因果关系，由 analyze 技能在分析相关错题时逐步填充
- `易混辨析`：容易混淆的概念对比和常见错误
- `考试技巧`：按题型的答题要点（地理注重读图，生物注重概念辨析）
- `相关知识点`：用 `[[知识点名]]` 语法链接到其他 wiki 页面，建立知识网络
- `例题`和`相关课程`：由其他技能（analyze、search-courses）自动关联补充

**c. 跳过已存在页面**

- 如果 Wiki 页面文件已存在，跳过不覆盖
- 记录跳过的知识点数量

### 第三步：更新索引文件

更新 `data/wiki/index.md` 索引文件：

```markdown
# 知识点索引

> 最后更新：{更新时间}

## 地理

### {章节名称}
- [{知识点名称}](./{文件名})

## 生物

### {章节名称}
- [{知识点名称}](./{文件名})

---

- 总计：X 个知识点（地理 Y 个，生物 Z 个）
- 骨架页面：W 个（待填充内容）
```

索引按学科 → 章节的层级组织，包含所有 Wiki 页面的链接。

### 第四步：汇报结果

导入完成后输出统计：
- 创建了 X 个新知识点页面
- 跳过了 Y 个已存在页面
- 更新了索引文件
- 总计：Z 个知识点（地理 A 个，生物 B 个）

## 规则

1. **不覆盖已有内容**：如果 Wiki 页面已存在且 status 不是 skeleton，不覆盖；如果是 skeleton 且为空，可补充
2. **文件名规范**：文件名中的序号使用两位数（01、02...），保持排序整齐
3. **索引同步**：每次导入后必须更新 `index.md`，确保索引与实际文件一致
4. **数据校验**：如果 `chapters.json` 格式不正确或缺少必要字段，报错并停止
5. **幂等性**：多次运行导入操作不会产生重复页面
6. **中文命名**：文件名和页面内容使用中文
7. **目录创建**：如果 `data/wiki/` 目录不存在，先创建目录
8. **批量处理**：如果知识点数量超过 50 个，提示用户确认后分批导入
