# stats — 学习统计

## 触发条件

用户说「统计」「学习报告」「看看数据」时触发。

## 工作流

### 第一步：扫描所有数据

1. **题目数据**：扫描 `data/questions/` 目录
   - 统计总题目数
   - 按 `subject` 分组（geography/biology）
   - 按 `analysis_status` 分组（pending/analyzed/error）
   - 统计 `needs_manual_review === true` 的题目数（需人工复核）
   - 按 `question_type` 分组（选择题/填空题/读图题/判断题/简答题）
   - 按 `difficulty` 分组（1/2/3）

2. **错题数据**：扫描 `data/mistakes/` 目录
   - 统计总错题数
   - 按 `is_mastered` 分组（已掌握/未掌握）
   - 按 `review_count` 分布统计
   - 计算掌握率（已掌握 / 总错题）
   - 统计到期需复习的题目数（`next_review_at <= 当前时间`）

3. **知识点数据**：扫描 `data/wiki/` 目录
   - 统计总知识点数
   - 按 `subject` 分组
   - 按 `status` 分组（skeleton/filled）
   - 计算知识点覆盖率（有相关错题的知识点 / 总知识点）

4. **练习题数据**：扫描 `data/practice/` 目录
   - 统计已生成的练习题总数
   - 按学科和题型分组
   - 统计练习题文件数量

### 第三步：保存报告

1. 将报告保存到 `data/reports/{YYYY-MM-DD}.md`
   - 文件名使用日期，同一天多次生成会覆盖
2. 如果 `data/reports/` 目录不存在，先创建目录
3. 同时在对话中展示报告内容

### 第四步：展示报告

- 直接在对话中输出完整报告
- 告知用户报告已保存到文件路径

## 规则

1. **数据准确**：所有统计数字必须来自实际文件扫描，不能使用缓存或估算
2. **空目录处理**：如果某些数据目录不存在或为空，对应统计显示为 0，不报错
3. **报告格式**：使用标准 Markdown 格式，包含表格便于阅读
4. **敏感信息**：报告中不包含用户个人信息
5. **增量对比**：如果存在历史报告，在报告末尾添加与上次报告的变化对比（新增题目、掌握率变化等）
6. **中文输出**：报告内容全部使用中文
7. **文件管理**：保留最近 30 天的报告文件，更早的可提示用户是否清理
8. **性能考虑**：如果数据量很大（超过 500 道题目），提示用户统计可能需要一些时间
