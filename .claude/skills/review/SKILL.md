# review — 错题复习

## 触发条件

用户说「复习错题」「该复习了」「看看到期题目」时触发。

## 工作流

### 第一步：读取到期错题

1. 扫描 `data/mistakes/` 目录下所有 JSON 文件
2. 筛选条件：`is_mastered === false` 且 `next_review_at <= 当前时间`
3. 按到期时间排序（最该复习的排前面）
4. 如果没有到期题目，提示「当前没有需要复习的题目，下次复习时间是 X」并结束

### 第二步：逐题展示复习

对每道到期题目，执行以下交互流程：

**a. 展示题目（不显示答案）**

向用户展示：
- 题目图片（读取 `data/questions/{id}/image.jpg`）
- OCR 识别的题目文字（`meta.json.ocr_text`）
- 题型和难度信息

重要：**不展示答案和解析**，等待用户自行回忆。

**b. 等待用户回忆**

提示用户：「请在心中回忆这道题的答案，准备好后说「看答案」。」

用户可能的操作：
- 说「看答案」→ 进入步骤 c
- 说「跳过」→ 标记本题跳过，进入下一题
- 说「暂停」→ 保存当前进度，暂停复习会话

**c. 展示答案和解析**

向用户展示：
- 正确答案（`analysis.answer`）
- 详细解析（`analysis.explanation`）
- 核心知识点（`analysis.key_concept`）
- 常见错误提醒（`analysis.common_mistakes`）

**d. 用户自评**

询问用户：「你记住了吗？」
- 用户说「记住了」/「会了」→ 标记为通过
- 用户说「没记住」/「还不会」→ 标记为未通过

### 第三步：更新复习状态

根据用户自评结果更新 `data/mistakes/{id}.json`：

**通过了（记住了）**：

```json
{
  "review_count": "原值 + 1",
  "last_reviewed_at": "当前时间（ISO 8601）",
  "next_review_at": "根据间隔算法计算",
  "review_history": "追加本次记录"
}
```

间隔复习算法（简化 SM-2）：

| review_count（更新后） | 下次复习间隔 |
|----------------------|------------|
| 1                    | 1 天后     |
| 2                    | 3 天后     |
| 3                    | 7 天后     |
| 4                    | 14 天后    |
| 5+                   | 30 天后    |

具体计算：`next_review_at = 当前时间 + 对应间隔天数`

**未通过（没记住）**：

```json
{
  "review_count": "保持不变（不增加）",
  "last_reviewed_at": "当前时间（ISO 8601）",
  "next_review_at": "当前时间 + 1天（保持高频复习）",
  "review_history": "追加本次记录，标记未通过"
}
```

**掌握判定**：
- 当 `review_count >= 3` 且最近一次复习通过时，可标记 `is_mastered: true`
- 标记掌握后该题目不再出现在复习队列中

### 第四步：汇报复习结果

复习会话结束后输出统计：
- 本次复习了 X 道题目
- 掌握了 Y 道（review_count 达标且通过）
- 还需继续复习 Z 道
- 下次最早复习时间

## 间隔复习算法详解

```
review_count 0 → 首次复习，通过后变为 1，下次 1 天后复习
review_count 1 → 通过后变为 2，下次 3 天后复习
review_count 2 → 通过后变为 3，下次 7 天后复习
review_count 3 → 通过后变为 4，下次 14 天后复习
review_count 4+ → 通过后变为 5+，下次 30 天后复习

未通过 → review_count 不变，下次始终 1 天后复习
```

## 规则

1. **先回忆后看答案**：严格遵守「先展示题目 → 等用户确认 → 再展示答案」的流程，不能提前暴露答案
2. **尊重用户节奏**：用户可以随时暂停或跳过，不强制完成所有题目
3. **间隔算法一致**：严格按照上述间隔复习算法计算下次复习时间，不随意调整
4. **掌握判定谨慎**：至少复习 3 次且全部通过才能标记为已掌握
5. **状态持久化**：每次复习后立即更新文件，不要等全部复习完再一次性写入
6. **复习记录可追溯**：`review_history` 中记录每次复习的时间、结果（通过/未通过）
7. **中文交互**：所有提示、说明、统计使用中文
8. **鼓励性反馈**：复习通过时给予鼓励性反馈，未通过时不批评，提示「加油，下次会更好」
