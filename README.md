# 🌍🔬 地生冲刺

> 八年级地理/生物会考错题录入和备考工具

## 快速开始

### 1. 启动服务

```bash
npm install
npm run dev
```

启动后会显示局域网地址：

```
📱 手机访问: http://192.168.x.x:3000
```

### 2. 手机录入

用手机浏览器打开上面的地址，然后：

1. **📸 拍照录入** — 点击首页大按钮 → 拍照/选图 → 裁剪框选题目区域
2. **📝 填写信息** — 选择学科（地理/生物）、章节、来源
3. **💾 保存** — 可勾选「同时加入错题本」
4. 页面显示「✅ 已保存，待电脑端分析」即成功

### 3. 电脑端处理（Claude Code）

在项目目录打开 Claude Code，使用以下技能：

| 技能 | 命令 | 说明 |
|------|------|------|
| 分析题目 | `/analyze` | OCR 识别 + 解题分析 + 自动创建知识点 |
| 搜索课程 | `/search-courses` | 搜索 B 站/小红书教学视频 |
| 生成练习 | `/generate-practice` | 基于错题自动生成类似练习题 |
| 复习错题 | `/review` | 间隔复习到期的错题 |
| 导入知识 | `/import-knowledge` | 初始化知识库（从预置章节创建 Wiki 页面） |
| 学习统计 | `/stats` | 查看录入/分析/复习数据报告 |

**日常使用流程：**

```
手机拍照录入 → 电脑 /analyze 分析 → 手机刷新查看解析
                              ↓
              /search-courses 补充课程视频
              /generate-practice 出题练习
              /review 复习到期错题
```

| Tab | 功能 |
|-----|------|

### 🖥️ 电脑端

- 所有 AI 功能通过 Claude Code 技能执行
- 数据存储在 `data/` 目录（JSON + 图片 + Markdown）
- 启动 Claude Code 时自动提示待分析题目数量

## 数据目录

```
data/
├── questions/{时间戳}/     # 题目（image.jpg + meta.json）
├── mistakes/{id}.json      # 错题记录（含间隔复习状态）
├── wiki/                   # 知识库（Markdown + YAML frontmatter）
│   ├── index.md            # 自动维护的知识点目录
│   ├── log.md              # 操作日志
│   └── *.md                # 知识点页面
├── practice/{时间戳}.json  # 练习题会话
├── chapters.json           # 预置章节+知识点结构
└── reports/                # 学习报告
```

## 知识库 Wiki

基于 [oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode) 的 LLM Wiki 模式实现：

- **追加策略** — 新内容追加到已有页面，永不覆盖
- **CJK 搜索** — 中文字符级 + 二元组分词
- **Wiki 链接** — `[[知识点名]]` 语法关联相关知识点
- **自动索引** — `index.md` 按学科分组自动维护
- **间隔复习** — 简化 SM-2 算法（1天→3天→7天→14天→30天）
- **健康检查** — 检测孤立页面、过期内容、断裂链接等

## 技术栈

- **前端**: React 19 + TypeScript + Vite 6 + Tailwind CSS（CDN）
- **后端**: Vite configureServer 中间件（单服务器）
- **存储**: 本地文件系统（JSON + 图片 + Markdown）
- **AI**: Claude Code 技能（终端执行）
- **无外部云服务、无数据库、无认证**

## 常见问题

**Q: 手机无法访问？**
> 确保手机和电脑在同一局域网。检查防火墙是否放行 3000 端口。

**Q: 图片裁剪不好用？**
> 裁剪组件支持：双指缩放、拖动平移、旋转。拖动右下角蓝色圆点调整裁剪框大小。

**Q: 知识库是空的？**
> 运行 `/import-knowledge` 初始化预置章节的知识点骨架。然后用 `/analyze` 分析题目时会自动补充知识点。

**Q: 如何查看搜索结果？**
> `/search-courses` 会搜索 B 站和小红书的教学视频，结果追加到对应知识点 Wiki 页面的「相关课程」部分。在手机端知识库页面查看。

**Q: 数据安全吗？**
> 所有数据存储在本地 `data/` 目录。建议定期备份该目录。
