## 七年级上册

### 第一单元 生物和生物圈

#### 第一章 认识生物

### 一 生物的特征

| 生物的特征 | 举例 |
| :--- | :--- |
| 生物的生活需要营养 | 植物的光合作用、动物的捕食 |
| 生物能进行呼吸 | 绝大多数生物需要吸入氧气、呼出二氧化碳 |
| 生物能排出体内产生的废物 | 植物落叶；动物和人排尿、出汗、呼气 |
| 生物能对外界刺激做出反应（应激性） | 含羞草受触会合拢叶片；动物发现敌害会逃跑 |
| 生物能生长和繁殖 | 种子萌发、蘑菇生长、幼儿长大——生长；鸟类产卵、兽类产仔——繁殖（或生殖） |
| 生物都有遗传和变异的特性 | "龙生龙，凤生凤，老鼠生儿会打洞"——遗传；"一母生九子，连母十个样"——变异 |
| 生物都是由细胞构成的 | 除病毒外，动植物、细菌、真菌等都由细胞构成 |

**注意：**

- ① "运动"不是生物的特征（如飞机、汽车也能运动）；
- ② 钟乳石也能"长大"，但不是"生长"（仅是物质的堆积），因此不是生物。

### 二 调查周边环境中的生物

1. **观察和调查**是科学探究的基本方法。
2. **调查的步骤：** 选择范围 → 分组 → 设计路线 → 调查 → 归类 → 整理
3. **调查时应注意的问题：**
   - ① 明确调查的目的和对象；
   - ② 注意保护生物及其生活的环境；
   - ③ 注意个人安全；
   - ④ 如实记录；
   - ⑤ 整理和分析调查的结果，有时还要用数学方法进行统计。

4. **生物的归类方法**
   - (1) 按形态结构特点分：**动物、植物和其他生物**。
   - (2) 按生活环境分：**陆生生物和水生生物**等。
   - (3) 按用途分：**作物、家禽、家畜、宠物**等。

## 第二章 了解生物圈

**生物圈**——地球上所有的**生物与其环境**的总和叫**生物圈**，是所有生物共同的家园。

### 一 生物与环境的关系

1. 生物的生活环境不仅指生物的生存空间，还包括存在于它周围的各种影响因素。环境中影响生物的生活和分布的因素叫作**生态因素**。生态因素可分为两类：一类是**非生物因素**（如光照、水分、温度、空气等），另一类是**生物因素**（如影响某种生物生活的其他生物）。

**(1) 非生物因素：**

| 非生物因素 | 举例 |
| :--- | :--- |
| 阳光 | 深海中无植物生长；菊花在短日照下开花；光照长短影响某些动物的繁殖 |
| 温度 | 山上植物开花晚；极地狐和沙漠狐耳朵大小不同；某些动物的冬眠和夏眠 |
| 水分 | 沙漠里植物很少；热带雨林地区动植物种类多 |

**(2) 生物因素：** 生物和生物的关系有种间关系（包括**捕食关系、竞争关系、寄生关系、共生关系**等）、种内关系（包括**种内互助、种内斗争**）。

| 种间关系 | 概念 | 举例 |
| :--- | :--- | :--- |
| 捕食关系 | 一种生物以另一种生物为食 | 狼吃羊；羊吃草；瓢虫吃蚜虫 |
| 竞争关系 | 两种生物生活在一起，相互争夺养料、空间等 | 水稻和稗草、牛和羊 |

**续表**

| 种间关系 | 概念 | 举例 |
| :--- | :--- | :--- |
| 寄生关系 | 一种生物生活在另一种生物体内或体表，从中吸取营养 | 蛔虫寄生在人体内；菟丝子寄生在其他植物上 |
| 共生关系 | 两种生物生活在一起，相互依赖，彼此有利；分开后两者都难以生存 | 犀牛和犀牛鸟；小丑鱼和海葵 |
| 种内互助 | 同种生物个体之间互相帮助，有利于物种的繁衍 | 蜜蜂或蚂蚁群体中的分工 |
| 种内斗争 | 同种生物个体之间为争夺食物、空间、配偶等而发生的斗争，有利于自然选择 | 一群鸡争食 |

2. **生物对环境的适应和影响**
   - (1) **生物适应环境**：如变色龙的保护色、仙人掌的针状叶、枯叶蝶的拟态等。
   - (2) **生物影响环境**：如"大树底下好乘凉""千里之堤，溃于蚁穴"等。

3. **科学探究的一般过程：** 提出问题 → 作出假设 → 制订计划 → 实施计划 → 得出结论 → 表达和交流。（注意设置**对照实验**，排除**偶然因素**）

### 二 生物与环境组成生态系统

1. **生态系统的概念：** 在一定的空间范围内，生物与环境所形成的统一的整体。如森林、农田、草原、湖泊、河流、公园等。

2. **生态系统的组成：**
   - **生态系统**
     - **生物部分**
       - **生产者**——绿色植物
       - **消费者**——绝大多数动物
       - **分解者**——细菌、真菌、某些腐食性动物（如蜣螂、秃鹫）
     - **非生物部分**——阳光、空气、水分、温度、土壤等

3. **生态系统的物质循环和能量流动：** 即**食物链和食物网**。

**食物链**——在生态系统中，不同生物之间由于吃与被吃的关系而形成的链状结构。

**食物网**——在一个生态系统中，往往有很多条食物链，它们彼此交错连接，形成食物网。

(1) 生态系统中的物质和能量是沿着食物链和食物网流动的，其中的物质是循环的，能量是单向流动、**逐级递减**的；

(2) 食物链中只有**生产者**和**消费者**，其起点是生产者，终点为**最高级消费者**（即不被其他动物捕食的动物）；食物链中不包括分解者和非生物部分。

(3) 箭头方向由被捕食者指向捕食者（例如：草→鼠→鹰）；箭头越往后，生物的营养级别越高，生物的数量也越少；一条食物链从生产者开始，循箭头指向直到最高级消费者为止；

(4) 一些有毒的物质（如农药、重金属）在生物体内比较稳定，不易分解，而且是生物体无法排出的。这些有毒物质在食物链内不断积累。营养级越高，有毒物质沿食物链积累就越多。

4. 生态系统具有一定的**自动调节能力**

一般情况下，生态系统中生物的数量和所占比例是相对稳定的（即生态平衡），这说明生态系统具有一定的自动调节能力。但这种自动调节能力有一定的**限度**，若超过这个限度，则生态系统会遭到破坏。一般生物种类越多、食物链和食物网越复杂，生态系统就越稳定。

## 三 生物圈是最大的生态系统

1. **生物圈的概念：** 地球上所有的生物与其环境的总和叫生物圈。生物圈是适合生物生存的地球表面的一薄层——海平面上下各约 10 千米（共约 20 千米）厚的范畴。

2. **生物圈的范围：** 大气圈的底部、水圈的大部和岩石圈的表面。

3. 生物圈为生物的生存提供了基本条件（如营养物质、水、阳光、空气、适宜的温度和生存空间等），是所有生物共同的家园。

4. **多种多样的生态系统**

| 类型 | 特点 |
| :--- | :--- |
| 森林生态系统 | 动植物种类繁多，在净化空气、涵养水源、保持水土方面起着重要的作用，有"**绿色水库**"、"**地球之肺**"之称 |
| 海洋生态系统 | 海洋面积大（约占地球表面积的 71%），是**制造氧气最多**的生态系统 |
| 湿地生态系统 | 具有净化水源、蓄洪抗旱的作用，有"**地球之肾**"之称 |
| 淡水生态系统 | 提供饮用、灌溉及工业用水，在调节气候等方面也有重要的作用 |
| 草原生态系统 | 多分布在干旱地区，在水土保持和防风固沙等方面起着重要的作用 |
| 农田生态系统 | 以农作物为主体，动植物种类较少，抗性较差，需投入大量人力和物力 |
| 城市生态系统 | 人类起支配作用，容易产生环境问题 |

地球上的各种生态系统并非彼此孤立，而是互相联系的，它们共同构成一个统一的整体——**生物圈**。

## 第二单元 生物体的结构层次

### 第一章 细胞是生命活动的基本单位

### 一 练习使用显微镜

1. **光学显微镜的构造**

**支持部分：** 镜座、镜柱、镜臂、载物台、镜筒、转换器

**调节部分：**
- 遮光器上的光圈——调节光线的强弱
- 粗、细准焦螺旋——调节镜筒的升降（其中粗准焦螺旋转动时镜筒升降的幅度更大）

**光学部分：**
- **反光镜：** 平面镜（光线强时用）；凹面镜（光线弱时用）
- **物镜：** 有螺旋；越长，则放大倍数越大（①②）
- **目镜：** 无螺旋；越长，则放大倍数越小（③④）

2. **显微镜的使用**

**口诀：** 一取二放三安装，四转低倍五对光；六上玻片七下降，八升镜筒细观赏。

(1) **取镜和安放：** 一手握镜臂，一手托镜座；放在实验台略偏左，距边缘约 7 cm；目镜、镜筒、物镜成一条直线。

(2) **对光：** 转动转换器，使**低倍物镜**对准通光孔；转动遮光器，使**较大的光圈**对准通光孔；左眼注视目镜，右眼睁开，转动反光镜，直到看到一个**明亮、圆形**的视野。
- 光线强时用**较小光圈**和**平面镜**；光线弱时用**大光圈**和**凹面镜**。

(3) **放片：** 把玻片标本放在载物台上，用压片夹压住；使标本正对通光孔。

(4) **观察：**
- ① 眼睛从侧面看，转动**粗准焦螺旋**，使镜筒下降，直到物镜接近玻片标本（约 2～3 mm），以免碰碎玻片。
- ② 左眼向目镜内看，同时逆时针方向转动粗准焦螺旋，使镜筒上升，直到看清物像。
- ③ 再略微转动**细准焦螺旋**，使物像更清晰。移动玻片，使物像位于视野中央。换高倍物镜时，转动转换器后，只用细准焦螺旋调节。

(5) **收镜装箱**

3. 显微镜下看到的物像是**倒立、放大的虚像**（即上下左右都相反）。物像移动方向与玻片移动方向相反，**物像偏哪边就往哪边移**；要看实际方向，可将图像旋转 180°。

4. **放大倍数 = 物镜倍数 × 目镜倍数**（低倍、高倍通常指物镜）。

| 物镜类型 | 细胞大小 | 看到的细胞数目 | 视野亮度 | 物镜与玻片距离 |
| :--- | :--- | :--- | :--- | :--- |
| 低倍物镜 | 小 | 多 | 亮 | 远 |
| 高倍物镜 | 大 | 少 | 暗 | 近 |

5. **污点位置的判定：** 污点可能在玻片、目镜或物镜上。镜头要用**擦镜纸**擦拭。
   - (1) 移动玻片：污点跟着移动，则在玻片上；否则不在。
   - (2) 转动目镜：污点跟着转动，则在目镜上；否则不在。
   - (3) 换物镜：污点消失或移动，则在物镜上；否则不在。

6. 生物标本必须**薄而透明**，让光线能透过。玻片标本分为**切片、装片、涂片**三种。

| 玻片类型 | 概念 | 举例 |
| :--- | :--- | :--- |
| 切片 | 用从生物体上切取的薄片制成 | 叶片的横切面、胃黏膜切片 |
| 装片 | 用撕下或挑取的少量生物材料制成 | 洋葱鳞片叶内表皮临时装片、人的口腔上皮细胞临时装片 |
| 涂片 | 用液体的生物材料涂抹制成 | 血液涂片、细菌涂片 |

7. 英国物理学家**罗伯特·虎克**用自制的显微镜观察软木切片，发现许多小室（实为死细胞的细胞壁），并命名为**"细胞"**。

### 二 植物细胞和动物细胞

1. **动植物细胞的结构及比较**

| 比较 | 植物细胞 | 动物细胞 |
| :--- | :--- | :--- |
| 不同点 | 有细胞壁和液泡，绿色部分的细胞有叶绿体 | 没有细胞壁、液泡、叶绿体 |
| 相同点 | 都有细胞核、细胞膜、细胞质、线粒体 | |

2. **细胞结构各部分作用**

| 结构名称 | 主要功能 |
| :--- | :--- |
| 细胞壁 | 支持、保护细胞 |
| 细胞膜 | 控制物质的进出（具有选择透过性）；保护细胞 |
| 细胞质 | 生命活动的主要场所（其内有叶绿体、线粒体、液泡等） |
| 叶绿体 | 植物细胞的能量转换器之一，是光合作用的场所 |
| 线粒体 | 动植物、真菌细胞的能量转换器，是呼吸作用的场所 |
| 液泡 | 内有细胞液，溶解着多种物质（如糖分、色素等） |
| 细胞核 | 贮存和传递遗传信息 |

3. **临时装片的制作**

| 临时装片 | 擦 | 滴 | 撕/刮 | 展/涂 | 盖 | 染 | 吸 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 洋葱表皮 | 用纱布擦干净玻片 | 清水 | 撕洋葱表皮 | 展平 | 盖盖玻片 | 碘液 | 吸去多余的水和碘液 |
| 口腔上皮 | 用纱布擦干净玻片 | 生理盐水 | 刮口腔内壁 | 涂抹 | 盖盖玻片 | 碘液 | 吸去多余的水和碘液 |

**操作步骤：** 擦 → 滴 → 撕/刮 → 展/涂 → 盖 → 染 → 吸

**注意：**
- ① 滴加清水或生理盐水的目的是使细胞保持正常形态，防止变形或破裂。
- ② 盖盖玻片时，用镊子夹住盖玻片一侧，使一侧先接触液滴，再缓缓放下，避免产生气泡。

**显微镜下的细胞与气泡比较：**

| 比较 | 特点 |
| :--- | :--- |
| 细胞 | 具有特定的形态结构，用镊子按压盖玻片不会变形；没有粗黑边缘 |
| 气泡 | 呈不规则圆形，轻压会变形；有粗黑边缘 |

4. 19 世纪 30 年代，德国生物学家**施莱登**和**施旺**共同创立了**细胞学说**——动植物体都是由细胞构成的，细胞是生物体结构和功能的基本单位。细胞学说与能量守恒定律、达尔文的进化论，被恩格斯列为 19 世纪自然科学的三大发现。

### 三 细胞的生活

1. 细胞是构成生物体的**结构**和**功能**的**基本单位**。
2. 细胞膜**控制物质的进出**。细胞中的物质分为两类：

| 细胞物质分类 | 概念 | 举例 |
| :--- | :--- | :--- |
| 无机物 | 一般不含碳，分子较小 | 水、无机盐、氧气、二氧化碳等 |
| 有机物 | 一般含碳，分子较大 | 糖类、脂质、蛋白质、核酸等 |

3. 细胞内的能量转换器：**线粒体**（动植物细胞均有）和**叶绿体**（大多数植物细胞有，动物细胞没有）。

| 能量转换器 | 特点 |
| :--- | :--- |
| 线粒体 | 动植物细胞均有，是呼吸作用的场所：将有机物中的化学能转化为其他形式的能 |
| 叶绿体 | 植物绿色部分才有，是光合作用的场所：将光能转化为化学能，储存在有机物中 |

4. 细胞核中有储存遗传信息的物质——**DNA**（脱氧核糖核酸），DNA 上有指导生物发育的全部信息；细胞核是细胞的控制中心。（证据：克隆羊多莉的性状与供核母羊性状相同）

**克隆羊多莉实验：** 供卵细胞母羊（无核卵细胞）+ 供核母羊（取出细胞核）→ 融合细胞 → 体外培养 → 胚胎 → 代孕母羊 → 克隆羊（与供核母羊性状相同）

5. 细胞的生活是物质、能量和信息变化的统一。

## 第二章 细胞怎样构成生物体

生物体发育通常从受精卵开始，通过细胞分裂、生长和分化，形成组织、器官和系统。动物和人体有"系统"层次，植物没有。

### 一 细胞的生长、分裂、分化

| 概念 | 结果 |
| :--- | :--- |
| 细胞生长：细胞从周围环境中吸收营养物质，体积由小变大（但不能无限长大） | 细胞体积增大（不能无限增大） |
| 细胞分裂：一个母细胞分成两个子细胞；母细胞与子细胞的染色体形态和数目相同 | 多细胞生物细胞数目增加；单细胞生物个体数目增加 |
| 细胞分化：子细胞在生长过程中形成形态、结构和功能不同的细胞 | 形成不同的组织 |

**动物细胞分裂：** 细胞核一分为二 → 细胞质分成两份 → 在细胞中央形成新的细胞膜

**植物细胞分裂：** 细胞核一分为二 → 细胞质分成两份 → 在细胞中央形成新的细胞膜和细胞壁

**染色体、DNA 的关系及其在细胞分裂过程中的变化：**

染色体由 DNA 和蛋白质组成；DNA 上有**基因**。

细胞分裂时，母细胞细胞核中出现了染色体 → 染色体会平均分配到两个子细胞中去 → 形成两个子细胞。

细胞分裂时，染色体的变化最明显——染色体复制加倍、平均分配到两个新细胞中，因此两个新细胞与母细胞细胞核里的染色体的形态、数目相同，即遗传物质相同。

| 结构层次 | 概念 | 举例 |

### 二 植株的生长

**根尖的纵剖图：** 成熟区、伸长区、分生区、根冠

**1. 幼根的生长**

根尖各部分的功能：

- **根冠：** 保护作用
- **分生区：** 属于分生组织，产生大量新细胞
- **伸长区：** 在长度上明显增加（生长最快）
- **成熟区：** 有根毛，是吸收水分、无机盐的主要部位

幼根的生长一方面要靠分生区细胞的分裂使细胞的数量增多，另一方面靠伸长区细胞的生长，使细胞体积增大。

**2. 枝条是由芽发育成的：** 幼叶 → 叶，芽轴 → 茎，芽原基 → 芽

芽按着生位置分为顶芽和侧芽，芽中有分生组织，细胞分裂和分化形成新的枝条（茎、叶、芽）。

**3. 年轮**反映了茎加粗生长的过程。加粗生长是茎的形成层细胞不断分裂和分化的结果。

**4. 植株的生长需要营养物质——水、无机盐、有机物**

1. **水、无机盐：** 由根从土壤中吸收，通过导管向上运输
2. **有机物：** 由叶片通过光合作用制造，通过筛管运输到其他器官
3. 植物需要量最多的是含氮、磷、钾的无机盐

| 种类 | 植株缺少时的症状 | 叶片缺少时的症状 | 作用 |
| --- | --- | --- | --- |
| 氮肥 | 矮小瘦弱 | 发黄，严重时叶脉呈淡棕色 | 促进细胞分裂和生长，使枝叶长得繁茂 |
| 磷肥 | 特别矮小 | 呈暗绿色，有的出现紫色 | 促进开花和果实、种子的成熟 |
| 钾肥 | 茎秆易倒伏 | 边缘和尖端呈褐色并逐渐焦枯 | 促进地下肥大根茎（如红薯、土豆）的生长；使茎秆健壮 |

**缺氮：** 植株矮小瘦弱，叶片发黄，严重时叶脉呈淡棕色

**缺磷：** 植株特别矮小，叶片呈暗绿色，并出现紫色

**缺钾：** 茎秆软弱，容易倒伏，叶片边缘和尖端呈褐色，并逐渐焦枯

此外，缺少含硼的无机盐，油菜就会只开花而不结果实。

**1. 花的结构**

花的主要结构是花蕊（包括雄蕊和雌蕊）。

- **雄蕊：** 花药、花丝
- **雌蕊：** 柱头、花柱、子房
- 其他：花瓣、萼片、花托、花柄

**2. 传粉和受精**

- **（1）传粉：** 花粉从花药落到柱头上的过程。包括自花传粉和异花传粉（昆虫传粉、风媒传粉）；人工辅助授粉可弥补自然状态下传粉不足。

## 第三章 绿色植物与生物圈的水循环

### 一 植物对水分的吸收和运输

1. 根是植物吸收水分的主要器官，吸收水分的主要部位是根尖的**成熟区**（生有大量根毛，扩大吸收面积）。移栽时要保护根尖。
2. 运输水分的结构是**导管**。根吸收的水和无机盐通过根内导管运输到茎，再到叶、花、果实等器官。

### 二 植物的蒸腾作用

1. 蒸腾作用：水分从活的植物体表面以水蒸气状态散失到大气中的过程。主要部位是**叶片**。植物吸收的水大部分用于蒸腾作用。
2. **叶片的结构：**
   - **表皮：** 包括上表皮和下表皮，属于保护组织
   - **叶肉：** 含有叶绿体，制造有机物，属于营养组织
   - **叶脉：** 含有导管和筛管，属于输导组织

表皮由一层细胞组成。气孔分布在表皮上（下表皮比上表皮多）。气孔是蒸腾作用的"门户"，也是气体交换的"窗口"。

气孔由一对半月形细胞——保卫细胞围成的空腔。保卫细胞内有叶绿体能进行光合作用，还能吸水膨胀，使气孔张开；保卫细胞若失水收缩，则气孔关闭。一般情况下，白天气孔张开，晚上气孔缩小或闭合。

### 三 绿色植物参与了生物圈的水循环（蒸腾作用的意义）

1. 可降低植物的温度，使植物不至于被太阳灼伤；
2. 促进植物体对水的吸收，促进水分和无机盐向上运输，保证各器官对水和无机盐的需要；
3. 提高大气湿度，增加降水，促进生物圈的水循环。

## 第四章 绿色植物是生物圈中有机物的制造者

### 一 绿叶在光下制造有机物

**1. 天竺葵实验**

实验步骤：①暗处理 → ②部分遮光 → ③取材 → ④脱色（酒精隔水加热） → ⑤漂洗 → ⑥碘液染色 → ⑦观察

照光部位变蓝黑色（有淀粉），遮光部位不变色。

| 实验步骤 | 操作过程 | 操作目的 |
| --- | --- | --- |
| ①暗处理 | 把天竺葵放到黑暗处一昼夜 | 让天竺葵在黑暗中把叶片中原有的淀粉运走、耗尽 |
| ②设置对照 | 将一片叶子的一部分从上下两面用黑纸片遮盖，后移到阳光下照射几小时 | 设置对照实验，看看照光的部位和不照光的部位是不是都产生淀粉 |
| ③取材 ④脱色 | 取下黑纸片，把叶片放入酒精中隔水加热（水浴加热） | 酒精能溶解叶片中的叶绿素，便于观察；隔水加热是因为酒精属于易燃物，直接加热会燃烧或爆炸 |
| ⑤漂洗 | 用清水漂洗 | 冲洗掉叶片上被酒精溶解出来的叶绿素 |
| ⑥染色 | 用碘液染色 | 检验光合作用的产物是不是淀粉 |
| ⑦观察 | 观察照光部位和不照光部位颜色的不同 | 检验照光的部位和不照光的部位是否产生了淀粉（原理：淀粉遇碘会变蓝） |

**实验结论：** 绿色植物光合作用需要光照，并在光照下产生了淀粉。

### 2. 有关光合作用的几个经典实验

**海尔蒙特实验：** 柳苗重 2.3 kg，干土重 90 kg → 柳苗重 76.8 kg，干土重 89.943 kg

海尔蒙特实验证实水是柳树苗长大的原料之一。

**普利斯特利实验**证实植物能更新污浊的空气。

**3. 光合作用的原理：** 绿色植物通过叶绿素捕获太阳光，利用光提供的能量，在叶绿体中合成淀粉等有机物，并且把光能转变成化学能，储存在有机物中。其实质是合成有机物、储存能量。


- 条件：光能、叶绿体
- 产物：有机物、氧气

**4.** 叶绿体既是生产有机物的"车间"（场所），也是将光能转变为化学能的"能量转换器"。

## 第五章 绿色植物与生物圈中的碳—氧平衡

### 一 绿色植物光合作用吸收二氧化碳释放氧气

1. **光合作用的概念：** 绿色植物在叶绿体中利用光能，把二氧化碳和水转化成有机物（如淀粉），并把光能转化为化学能储存在有机物中，同时释放氧气。
2. **光合作用的实质：** 合成有机物、贮存能量。
3. **光合作用的意义：** 为植物自身生长发育繁殖提供有机物；为生物圈中其他生物提供有机物和能量来源。
4. 不断消耗大气中的二氧化碳，释放氧气，维持生物圈中碳—氧平衡。
5. 氧气能使带火星的木条或快要熄灭的卫生香复燃。
6. **农业生产应用：** 合理密植；温室蔬菜可适当延长光照时间、补充二氧化碳。

### 二 绿色植物的呼吸作用

1. **呼吸作用的概念：** 细胞利用氧，将有机物分解成二氧化碳和水，同时释放出储存在有机物中的能量，供生命活动利用。
2. **呼吸作用的部位：** 活细胞中的线粒体。
3. **呼吸作用的实质：** 分解有机物、释放能量。
4. **呼吸作用的意义：** 释放的能量为生命活动提供动力（细胞分裂、吸收无机盐、运输有机物等）；一部分以热能形式散失。
5. 二氧化碳能使澄清石灰水变浑浊。
6. **应用：** 促进呼吸（松土、及时排水）；抑制呼吸（低温干燥、降低氧浓度）。

**7. 种子呼吸现象的三个演示实验**（甲中是萌发种子，乙中是煮熟并冷却的种子）

1. **释放热量：** 种子呼吸释放热量，使温度升高
2. **消耗氧气：** 种子呼吸消耗氧气
3. **释放二氧化碳：** 种子呼吸释放二氧化碳

**8. 光合作用和呼吸作用的区别和联系**

| 区别 | 光合作用 | 呼吸作用 |
| --- | --- | --- |
| 场所 | 叶绿体 | 主要是线粒体 |
| 条件 | 有光 | 有光、无光均可 |
| 原料 | 二氧化碳、水 | 有机物、氧 |
| 产物 | 有机物、氧 | 二氧化碳、水 |
| 物质转变 | 合成有机物 | 分解有机物 |
| 能量转变 | 储存能量 | 释放能量 |
| 反应式 | 二氧化碳 + 水 →(光/叶绿体)→ 有机物（储存能量）+ 氧 | 有机物 + 氧 → 二氧化碳 + 水 + 能量 |

**联系：** 相互依存

### 绿色植物在生物圈碳—氧平衡中的作用

1. 维持大气中二氧化碳和氧气的相对稳定；
2. 减缓温室效应的发展；
3. 促进人们植树造林、控制二氧化碳的排放量，营造"低碳生活"。

## 第六章 爱护植被，绿化祖国

### 我国主要的植被类型

一个地区内生长的所有植物叫作这个地区的植被。我国的植被中，森林占据主体。我国主要的植被类型有：

1. 草原：以草本耐旱植物为主
2. 荒漠：植物种类贫乏，植物十分耐旱
3. 热带雨林：高温多雨，植物终年常绿
4. 常绿阔叶林：以常绿阔叶树为主
5. 落叶阔叶林：以落叶阔叶树为主
6. 针叶林：以松和杉等针叶林为主

### 我国植被面临的主要问题

1. 森林面积正在逐渐减少
2. 草场正在日益退化和沙化
