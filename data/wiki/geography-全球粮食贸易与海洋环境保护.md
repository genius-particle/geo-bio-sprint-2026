# 全球粮食贸易与海洋环境保护

## 核心知识

- **粮食贸易格局**：大洋洲（澳大利亚）向我国出口**小麦** → 澳大利亚地广人稀、农业机械化程度高，是重要的小麦出口国；**橄榄油**主要来自**欧洲**（地中海沿岸国家如西班牙、意大利、希腊） → 地中海气候适合油橄榄生长。
- **赤道穿过的大洲**：赤道共穿过**6个大洲中的3个**——**南美洲、非洲、亚洲、大洋洲**（其中亚洲和大洋洲各被赤道穿过一小部分岛屿） → 做题时注意不能漏掉亚洲（印度尼西亚）和大洋洲（基里巴斯等岛屿）。
- **海洋环境威胁**：**过度捕捞** → 渔业资源枯竭；**塑料污染** → 海洋生物误食或被缠绕；**石油泄漏** → 破坏海洋生态；**温室气体排放** → 海平面上升、珊瑚白化。
- **海洋保护对策**：**休渔期制度** → 让鱼类繁殖恢复；**限塑令** → 减少塑料入海；**海洋环境监测** → 及时发现污染；**建立海洋保护区** → 保护关键生态区域。
- **国际合作的重要性**：海洋是连通的，一国无法单独解决 → 需要国际条约和协作（如《联合国海洋法公约》） → 体现"人类命运共同体"理念。

## 易混辨析

- **赤道穿过的大洲数量**：赤道穿过的大洲有**南美洲、非洲、亚洲、大洋洲**共4个（不是3个！） → 容易漏掉亚洲（印尼群岛）或大洋洲。注意题目问"赤道穿过的大洲"还是"赤道穿过的大陆"——穿过的大陆只有南美洲和非洲2个。
- **贸易路线 vs 运河**：巴拿马运河连接太平洋和大西洋，是航运要道，但不是粮食产地 → 题目问"某国进口粮食来源"时，看出口国而非运输通道。
- **橄榄油 vs 普通食用油**：橄榄油产地集中在**地中海沿岸**（欧洲南部），而不是热带地区 → 大豆油、棕榈油才是热带/亚热带产区的产品。

## 考试技巧

- 问"赤道穿过哪些大洲"时，口诀记忆：**"南非亚大"**（南美洲、非洲、亚洲、大洋洲）→ 注意"大"是大洋洲，不是"大洲"的简称。
- 问"海洋环境问题及对策"时，采用**问题→对策配对**回答：过度捕捞→休渔；塑料→限塑；油污→监测治理。避免只罗列问题不给对策。
- 粮食贸易题目先确认**出口国**的地理特征（气候、地形）→ 再推导其农产品优势。
