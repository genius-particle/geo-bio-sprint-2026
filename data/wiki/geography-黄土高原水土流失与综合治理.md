# 黄土高原水土流失与综合治理

## 核心知识

- **成因**：夏季降水集中多暴雨 + 黄土土质疏松 + 地表植被稀疏 → **水土流失**严重 → 地表被切割成千沟万壑的破碎地貌。
- **治理措施（因地制宜）**：
  - 陡坡：**植树种草**（退耕还林还草），恢复植被；
  - 缓坡：修筑**梯田**，减缓水流速度；
  - 沟谷：**打坝淤地**，拦泥蓄水，建设稳产高产农田。
- **延安苹果优势**：
  - 海拔高 → 气温低 → 生长周期**长** → 果实积累养分更多；
  - 云量小 → 晴天多、**光照充足**，光合作用强；
  - 昼夜温差大 → 白天光合产物多，夜晚呼吸消耗少 → **糖分大量积累**。
- **产业发展方向**：科技投入（品种改良）、品牌建设、深加工（果汁/果干）、电商销售 → 增加附加值，实现**可持续发展**。
- **霜降前后**属**秋季**（10 月下旬），不是冬季 — 此时气温下降但尚未入冬，柿饼制作正是利用秋末干燥凉爽的气候条件。

## 易混辨析

### 霜降是秋季还是冬季
- **霜降**（10 月 23 日左右）是**秋季节气**，不是冬季。
- 考试中"霜降前后"出现的农业生产活动，应归入秋季。

### 只答经济增收，漏答可持续发展
- 题目问"发展某产业的意义/好处"时：
  - 不能只答"增加收入""促进就业"等经济效益；
  - 还要答**可持续发展**角度：保护生态环境、防止水土流失、实现经济与生态双赢。

### "因地制宜"怎么答
- 黄土高原的治理必须结合地形条件分区施策，不能"一刀切"。
- 答题时按"陡坡—缓坡—沟谷"三个地形部位分别写措施，才能体现"因地制宜"。

## 考试技巧

1. **水土流失成因题**：从气候（暴雨）、土壤（疏松）、植被（稀疏）、地形（坡度大）四个角度分点作答。
2. **治理措施题**：按地形部位分答 — 陡坡植树/缓坡梯田/沟谷打坝，体现"因地制宜"。
3. **农产品品质好的原因**：固定答"光照 + 温差 + 生长期"三个角度 → 光照强、温差大、生长期长 = 高品质。
4. **产业发展建议题**：从"科技+品牌+加工+销售（电商）"四个角度回答，结尾点明"可持续发展"。
