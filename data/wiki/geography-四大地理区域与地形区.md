# 四大地理区域与地形区

## 核心知识

- **四大地理区域**：北方地区、南方地区、西北地区、**青藏地区**。划分依据是地理位置、自然环境和人文特征的差异。
- **北方地区**：跨**华北平原**、东北平原、黄土高原；主要粮食作物为小麦；气候属**温带季风气候**，冬季寒冷干燥、夏季高温多雨。
- **南方地区**：跨长江中下游平原、东南丘陵、云贵高原、四川盆地；主要粮食作物为水稻；气候属**亚热带季风气候**，水热条件优越。
- **西北地区**：深居内陆 → 距海远 → 降水少 → **干旱**是主要自然特征；农业以**畜牧业**和**绿洲农业**为主。
- **青藏地区**：海拔高 → 气温低 → **高寒**是主要自然特征；**太阳能**和**地热能**丰富，清洁能源（绿电）充足。
- **青海**：位于青藏地区，清洁能源丰富 → 本地用电需求小 → 可以向外输送绿电。
- **河南**：位于**华北平原**，人口稠密 → 用电需求大 → 是西电东送的受端。
- **西电东送**：将西部丰富电能输送到东部能源紧张地区 → 缓解东部能源压力 → 体现**区域协调发展**战略。

## 易混辨析

| 易混点 | 正确理解 |
|--------|----------|
| "西北=干旱""青藏=高寒" | 西北的关键词是**干旱**（降水少），青藏的关键词是**高寒**（海拔高气温低），成因不同：一个因距海远，一个因海拔高 |
| 青海 vs 青藏高原 | 青海是省级行政区，青藏高原是地形区，青海只是青藏高原的一部分 |
| 西电东送 vs 南水北调 | 西电东送输送的是**电能**，南水北调输送的是**水资源**，两者都是跨区域资源调配 |
| 华北平原 vs 华北地区 | 华北平原是地形区，华北地区（北方地区的一部分）是地理区域，范围不完全重合 |

## 考试技巧

- 题目出现"绿电出高原""清洁能源外送"等表述 → 联想到**青藏地区**的太阳能/地热能优势和**西电东送**。
- 判断区域归属时，先看**地理位置**（纬度、海陆位置、海拔），再看**自然特征**（气候、地形），最后对应四大区域。
- 考区域差异比较题时，按"地形 → 气候 → 河流 → 农业 → 工业"的链条逐条比较，不易遗漏。
