# 温带季风气候读图

## 核心知识

- **温带季风气候特征**：夏季高温多雨，**冬季寒冷干燥**。最冷月（1 月）均温低于 0°C → 河流有结冰期。
- **典型分布区**：**华北地区**（如北京、天津、河北、山东等地），以及东北大部分地区。
- **春季特征**（3—5 月）：**升温快、降水少** → 气温回升快但降水不足 → 容易出现**春旱**（春季干旱）。
- **降水季节分配**：降水主要集中在 7—8 月（夏雨型）→ 全年降水不均匀。
- **气温曲线判读要点**：看最冷月温度 → 低于 0°C = 温带；看降水分布 → 集中夏季 = 季风气候。
- **春旱的影响**：春季升温快 + 降水少 +多大风 → 蒸发旺盛 → 土壤缺水 → 影响冬小麦返青和春播。

## 易混辨析

| 易混点 | 正确理解 |
|--------|----------|
| 春季气候描述 | 春季是"**升温快、降水少**"，不是"寒冷干燥"（寒冷干燥是**冬季**的特征）。春季气温已在回升，只是降水还没跟上 |
| 温带季风 vs 亚热带季风 | 最冷月均温 < 0°C → 温带季风（北方）；最冷月均温 > 0°C → 亚热带季风（南方）。0°C 线（秦岭—淮河一线）是分界 |
| 华北 vs 南方 | 华北属温带季风气候，冬季冷、降水少；南方属亚热带季风气候，冬季温和、降水较多。不能把华北当成南方 |
| 温带季风 vs 温带大陆性 | 温带季风 = 夏雨集中、冬季干燥；温带大陆性 = 全年少雨、温差更大。关键看**降水是否集中夏季** |

## 考试技巧

- 判读气候图三步法：第一步看**最冷月温度**（判断温度带）→ 第二步看**降水总量和季节分配**（判断气候类型）→ 第三步对应**典型分布区**。
- "春季"相关题目 → 关键词是"升温快、降水少、春旱"，不要误选冬季特征。
- 题目给出气候图问"分布在哪" → 温带季风气候直接对应**华北地区**或北方地区。
- 气温曲线低于 0°C 的月份多 → 温带；低于 0°C 的月份少或没有 → 亚热带。
