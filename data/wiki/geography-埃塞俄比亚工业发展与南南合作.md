# 埃塞俄比亚工业发展与南南合作

## 核心知识

- **位置**：非洲东部（东非高原），主要人种为**黑**色人种 → 非洲是黑种人的故乡。
- **内部区域差异**：该国**北部**为棉花种植区 → 提供纺织原料；**南部**有阿瓦萨工业园 → 服装加工出口。
- **工业区位优势**：**土地价格低、劳动力价格低**、政府投资支持、独立供电、电价低等。注意：不是简单写"原料充足"，要写清楚是**土地和劳动力成本低**。
- **出海通道**：埃塞俄比亚是**内陆国**（没有海岸线）→ 经**吉布提港**出海 → 吉布提港位于**印度洋**沿岸。
- **国际合作**：埃塞俄比亚与中国同属**发展中国家** → 发展中国家之间的合作称为**南南合作**（不是南北对话）。
- **南南合作 vs 南北对话**：发展中国家之间的合作 = 南南合作；发展中国家与发达国家之间的谈判 = 南北对话。

## 易混辨析

| 易混点 | 正确理解 |
|--------|----------|
| "原料充足" vs "土地和劳动力成本低" | 题目问工业优势条件时，埃塞俄比亚的核心优势是**土地和劳动力价格低**，不是原料充足（虽然北部种棉花，但工业区位优势应强调成本优势） |
| 南南合作 vs 南北对话 | 南南 = 发展中国家之间（如中国与埃塞俄比亚）；南北 = 发展中国家与发达国家之间（如中国与美国） |
| 埃塞俄比亚的出海港口 | 埃塞俄比亚本身是内陆国，需借道**吉布提港**（印度洋），不是红海也不是大西洋 |
| 非洲所有人都是黑种人 | 非洲北部（如埃及）以白种人为主，撒哈拉以南非洲才是黑种人集中分布区。埃塞俄比亚在东非，属黑种人为主 |

## 考试技巧

- 看到"埃塞俄比亚工业园"相关题目 → 先判断考察的是**工业区位优势**还是**国际合作类型**。
- 工业区位优势答题模板：自然条件（原料、水源）+ 经济条件（**土地价格、劳动力成本**）+ 社会条件（政策、交通）+ 技术条件，逐条列举。
- "合作类型"判断：看双方都是发展中国家 → 南南合作；一方是发达国家 → 南北对话。
- 非洲国家题目常考人种判断 → 记住"撒哈拉以南 = 黑种人"。
