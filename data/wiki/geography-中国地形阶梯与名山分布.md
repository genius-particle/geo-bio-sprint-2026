# 中国地形阶梯与名山分布

## 核心知识

- **中国地势三级阶梯**：第一级（青藏高原，平均 4000m+）→ 第二级（高原盆地，1000-2000m）→ 第三级（平原丘陵，500m 以下）。
- **十大名山多分布在第二级阶梯**（青藏高原东缘至云贵高原一带），因为这一带地形落差大、地质活动强烈 → 形成雄伟山峰。
- 拥有名山最多的省份是**西藏**和**四川** → 西藏有珠峰、南迦巴瓦等，四川有贡嘎山、峨眉山、稻城三神山等。
- **南迦巴瓦峰**位于西藏林芝地区，当地主要为**藏族**聚居区。
- **乔戈里峰（K2）**位于**新疆维吾尔自治区**与巴基斯坦边境 → 世界第二高峰（8611m），攀登难度远超珠峰。
- **横断山脉**名山集中：梅里雪山、稻城三神山、贡嘎山、峨眉山等 → 横断山脉是第一、二级阶梯的过渡地带。
- **泰山植被**为**温带落叶阔叶林** → 答题时必须写完整，带"温带"前缀，不能只写"落叶阔叶林"。
- **泰山位于山东省**，属于第三级阶梯（华北平原东侧），是五岳之首。

## 易混辨析

| 易混点 | 正确理解 | 常见错误 |
|--------|---------|---------|
| 泰山在哪个阶梯？ | 泰山在**第三级阶梯**（山东丘陵），不在第二级 | 以为名山都在第二级阶梯就误判泰山位置 |
| 植被名称 | 泰山植被必须写"**温带落叶阔叶林**"，要带气候带前缀 | 只写"落叶阔叶林"会被扣分 |
| 乔戈里峰在哪？ | **新疆维吾尔自治区**（非西藏）与巴基斯坦交界 | 误以为所有高峰都在西藏 |
| 横断山脉名山 | 梅里雪山、贡嘎山、峨眉山等 → 都在**川西至滇西北** | 以为峨眉山不在横断山脉范围内 |
| 南迦巴瓦峰民族 | 西藏林芝 → **藏族**聚居区 | 误答其他少数民族 |

## 考试技巧

- **名山分布题**→ 先判断该山在哪个阶梯（大多数名山在第二级，但泰山在第三级是例外）。
- **植被名称题**→ 一定要写完整的植被带名称，带气候带前缀。泰山 = 温带落叶阔叶林，峨眉山 = 亚热带常绿阔叶林。
- **"名山最多的省"**→ 记住西藏、四川并列第一。西藏靠海拔高、四川靠横断山脉地形复杂。
- **阶梯过渡带**→ 第一→第二级阶梯分界线：昆仑山—祁连山—横断山脉；第二→第三级阶梯分界线：大兴安岭—太行山—巫山—雪峰山。
