# 美国气候与农业

## 核心知识

- **主要气候**：本土大部分为**温带大陆性气候**，冬冷夏热，温差大，降水集中在夏季。
- **西部沿海气候**：**地中海气候**（夏季炎热干燥、冬季温和多雨）和**温带海洋性气候**（全年温和湿润）均位于西岸 → 受西部山地（落基山脉、海岸山脉）阻挡太平洋水汽，气候带范围狭窄。
- **农业特征**：地区生产**专业化**，每个农业带专注一种或少数几种农产品。
- **乳畜带**（A 区）：分布在**五大湖**附近 → 气候**冷湿**、适宜牧草生长 → 加上城市人口密集、**市场需求大**，发展乳畜业。
- **进口热带产品**：本土以温带为主，热带面积小（仅夏威夷等） → 咖啡、可可、天然橡胶等热带农产品需要大量进口。
- **中部大平原**：地势平坦、土壤肥沃、水源充足 → 玉米带、小麦区 → 美国"粮仓"。

## 易混辨析

### 美国西部沿海两种气候
- **地中海气候**：分布在美国西海岸**南部**（如洛杉矶），夏季干燥、冬季多雨。
- **温带海洋性气候**：分布在美国西海岸**北部**（如西雅图），全年温和湿润。
- **区分关键**：看纬度位置 — 南边是地中海气候，北边是温带海洋性气候。

### 乳畜带的区位因素
- 学生常只答"气候冷湿" → 还要答**市场需求**（五大湖附近城市密集，对乳制品需求大）。
- 冷湿 → 牧草好（自然条件）；城市多 → 市场大（社会经济条件）。**两个条件缺一不可**。

## 考试技巧

1. **答气候影响农业**：先说气候类型和特点 → 再说对农作物或畜牧业的影响 → 最后说市场/交通等社会经济条件。
2. **"为什么进口热带产品"类题**：从纬度位置出发 → 本土主要在温带 → 热带面积小 → 无法大规模种植 → 需要进口。
3. **农业带判断**：记住各农业带位置和对应条件 — 乳畜带（冷湿+市场）、玉米带（温带草原）、小麦区（半干旱）、棉花带（热量充足）。
4. **美国气候题常考"为什么西海岸气候带狭窄"** → 答案：西部山脉南北走向，阻挡太平洋湿润气流深入内陆。
