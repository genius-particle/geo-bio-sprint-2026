# 台湾省的自然特征与外向型经济

## 核心知识

- **位置**：台湾省位于我国东南海域，与福建省隔**台湾海峡**相望 → 台湾海峡是东海与南海的分界线，属于大陆架浅海。
- **组成**：包括台湾岛、**澎湖列岛**、钓鱼岛、兰屿、绿岛等许多小岛 → 台湾岛是我国第一大岛。
- **地形与人口分布**：台湾岛多山，**台湾山脉**纵贯东部（最高峰玉山3952m，也是我国东部最高峰）→ 西部为沿海平原 → **人口和城市主要分布在西部沿海平原**（地形平坦、交通便利、开发历史悠久）→ 东部山地多、平原少，人口稀疏。
- **气候**：以**亚热带季风气候**为主（北部），南部为热带季风气候 → 与福建省气候类型相似，温暖湿润，雨热同期。注意：不能只写"亚热带"，必须写全"**亚热带季风气候**"。
- **农业特色**：盛产**甘蔗**，有"东方甜岛"之称 → 温暖湿润的气候适合甘蔗生长；还产香蕉、菠萝等热带、亚热带水果。
- **经济发展**：20世纪60年代发展出口加工工业 → 90年代以来重点发展**高技术产业**（电子、信息、半导体等）→ 经济类型为**外向型经济**（进口原料→加工出口→依赖国际市场）→ 祖国大陆是台湾最大的贸易伙伴。

## 易混辨析

- **人口分布方向**：台湾人口集中在**西部**沿海平原 → 因为西部地形平坦、交通便利。容易误填"东部"，但东部是山地，人口稀疏。记住口诀：**"西山人多，东山人少"**。
- **气候名称写全**：台湾的气候是"**亚热带季风气候**"，不能只写"亚热带气候"或"亚热带" → "季风"两个字不能丢，丢了就不完整。同理，南部是"热带季风气候"而不是"热带气候"。
- **外向型经济 vs 自给自足**：台湾面积小、资源有限 → 无法自给自足 → 必须依靠**进口原料、出口产品** → 这是外向型经济的核心逻辑。
- **澎湖列岛 vs 海南岛**：澎湖列岛是台湾省辖下的岛群，位于台湾海峡中；海南岛是独立的省级行政区，不属于台湾省。

## 考试技巧

- 题目描述"从福建乘船赴台"时，横穿的是**台湾海峡** → 可联想海峡两岸的地理联系。
- 问"台湾人口分布特点及原因"时，答题格式：分布在**西部沿海平原** → 原因：①地形平坦 ②交通便利 ③开发历史悠久 ④气候适宜。分点作答，条理清晰。
- 问"台湾发展高技术产业的优势"时，从**人才（教育水平高）→ 产业基础（早期加工工业积累）→ 地理位置（邻近祖国大陆和东南亚市场）→ 政策支持**四个角度回答。
