# 中国海洋资源

## 核心知识

- **海洋渔业资源**丰富：中国海域跨越多个温度带 → 鱼类种类多。**舟山渔场**为全国最大渔场（东海海域，寒暖流交汇）。
- **海底矿产（油气）**：集中在**渤海**和**南海**北部大陆架 → 大陆架水深较浅，有利于油气勘探和开采。
- **海洋可再生能源**：海上风电、潮汐能、波浪能等 → 属于清洁能源，未来发展潜力大。
- **海盐生产**：中国是世界上海盐产量最大的国家。盐场条件 = 降水少 + 晴天多 + **蒸发量大** + 地势平坦的泥质海滩。
  - **长芦盐场**（天津/河北）：北方沿海，降水少、晴天多、蒸发旺盛。
  - **布袋盐场**（台湾西部）：位于台湾山脉**背风坡** → 降水少、蒸发旺。
- **海水养殖**：大力发展海水养殖 → 减轻野生渔业资源压力，实现海洋资源的可持续利用。
- **海洋环境保护**：过度捕捞 → 渔业资源衰退；海洋污染 → 生态破坏 → 必须加强保护。

## 易混辨析

| 易混点 | 正确理解 | 常见错误 |
|--------|---------|---------|
| 油气分布海域 | 渤海（近海）和**南海北部**大陆架 | 误以为东海油气最多（东海也有，但题目通常考渤海和南海） |
| 布袋盐场成因 | 台湾山脉**背风坡** → 焚风效应 → 降水少蒸发旺 | 以为台湾到处多雨，忽略山脉的雨影效应 |
| 晒盐条件关键词 | 答题必写"**蒸发量大**"，不能只写"晴天多" | 只答"降水少"或"温度高"而不写"蒸发量大" |
| 渔场成因 | 舟山渔场 = **寒暖流交汇** + 大陆架浅 + 河流入海带来营养盐 | 以为渔场只是因为"鱼多"，不知道具体成因 |

## 考试技巧

- **盐场条件题**→ 四要素口诀："降水少、晴天多、蒸发量大、泥质海滩"。布袋盐场额外加上"背风坡"。
- **油气资源题**→ 看到大陆架就想到渤海和南海，答题时写具体海域名称，不要笼统写"近海"。
- **海洋资源分类**→ 渔业（生物资源）、油气（矿产）、潮汐能（能源）、海盐（化学资源）→ 四大类要分清。
- **可持续发展题**→ 海水养殖 + 休渔期 + 海洋保护区 → 从"保护"和"合理开发"两个角度作答。
