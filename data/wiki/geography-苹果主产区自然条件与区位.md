# 苹果主产区自然条件与区位

## 核心知识

- **35°N—40°N 黄金地带**：该纬度带光照充足、昼夜温差适中，是世界苹果优生区。陕西苹果基地位于渭河平原与**黄土高原**过渡地带。
- **黄土高原苹果优势**：坡地种果树 → 既保持水土又增加收入，实现**生态效益与经济效益双赢**。
- **昭通苹果**：纬度**低**（约 27°N）→ 热量充足 → 苹果**成熟更早**，可错峰上市抢占市场。
- **阿克苏苹果**：灌溉水源为**高山冰雪融水**（非河水或地下水）；深居内陆 → 降水少、**云量小** → 光照极强、**昼夜温差大** → 糖分大量积累 → 口感甜脆。售价高还因**运输距离远、成本高**。
- **苹果品质好的通用答题角度**：光照强（光合作用旺盛）+ 昼夜温差大（糖分积累）+ 灌溉水源清洁。
- **社会经济区位**：交通便利（便于外销）、技术支持（品种改良、科学管理）、市场需求大、政策扶持。

## 易混辨析

### 阿克苏的灌溉水源
- **正确**：高山冰雪融水（来自天山等高山）。
- **常见错误**：答"河水"或"地下水" — 冰雪融水是阿克苏地区最核心的灌溉水源，考试要答准确。

### 苹果售价高的原因
- 不能只答"品质好" → 还要答**运输成本高**（阿克苏距东部消费市场远）和**错峰上市**（物以稀为贵）。
- 答题模板：品质优（自然条件）+ 运输成本高（交通因素）+ 上市时间独特（市场因素）。

### 昭通 vs 阿克苏的"不同优势"
- **昭通**：纬度低 → 热量足 → **早熟**，抢占先机。
- **阿克苏**：深居内陆 → 温差大 → **糖分高**，品质突出。
- 两者优势来源不同，不能混为一谈。

## 考试技巧

1. **分析某地适合种苹果**：从自然条件（纬度/光照/温差/水源/地形）和社会经济条件（市场/交通/技术/政策）两个角度分点作答。
2. **"为什么坡地种苹果比种粮好"**：答保持水土（生态）+ 经济收入更高（经济）→ 一举两得。
3. **"为什么某地苹果品质好/售价高"**：品质答自然条件（光照+温差+水源），售价答运输成本+市场供需+品牌价值。
4. **读图题注意**：看经纬度判断位置 → 推断气候类型 → 联系农业条件。
