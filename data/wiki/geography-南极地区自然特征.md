# 南极地区自然特征

## 核心知识

- **欺骗岛（Deception Island）**：位于南极半岛附近，约**63°S** → 是一座活火山岛，火山口被海水淹没形成天然港湾 → 常见景观是**海面漂浮的冰山**（非冰川裂缝、非极光）。
- **南极地区典型景观**：**冰山**（海面漂浮）、**企鹅**（代表性动物）、**极昼极夜**现象、**冰川/冰盖**（覆盖大陆）。椰林（热带）、斑马（非洲草原）、骆驼（沙漠）均不是南极景观。
- **南极圈范围**：南极圈位于**66.5°S** → 只有南极圈以内才有**极昼极夜**现象。欺骗岛约63°S → 在南极圈**以北** → **没有极昼极夜现象**。
- **南极地区气候特征**：**酷寒**（世界最冷的大洲，年均温-25°C）、**干燥**（"白色荒漠"，降水极少）、**烈风**（风速极大，被称为"风库"）→ 合称"三大特征"。
- **南极地区的科学价值**：未经人类大规模开发 → 保存了最原始的自然环境 → 是研究地球演化、气候变化、天文学的**天然实验室** → 多国在此设立科考站（我国有长城站、中山站、昆仑站、泰山站）。

## 易混辨析

- **欺骗岛的位置认知**：欺骗岛在南极半岛附近，但纬度约63°S → 未进入南极圈 → **不能出现极昼极夜**。考试容易把"南极地区"和"南极圈内"混淆：南极地区范围更广，南极圈内才有极昼极夜。
- **冰山 vs 冰川**：**冰山**是漂浮在海面上的大块冰，是冰川断裂入海形成的；**冰川**是覆盖在陆地上的巨大冰体。南极洲表面覆盖的是冰川，近海看到的是冰山。
- **北极 vs 南极的动物**：南极有企鹅、海豹、鲸；北极有北极熊、北极狐。企鹅**只生活在南半球**，北极熊**只生活在北半球**，两者不会出现在同一极地。

## 考试技巧

- 极地景观选择题：先排除明显不属于极地的选项（椰林、斑马、骆驼等热带/温带景观）→ 再在"冰山""极光""企鹅"等极地景观中选择题目描述最匹配的。
- 判断某地是否有极昼极夜，先看**纬度是否在极圈以内**（66.5°以上）→ 欺骗岛63°S不在圈内 → 无极昼。这个推理过程很重要，不要凭感觉答题。
- 南极题目常考"三大特征"（酷寒、干燥、烈风），记住关键词即可快速答题。
