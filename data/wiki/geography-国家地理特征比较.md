# 国家地理特征比较

## 核心知识

- **日本**：岛国，多山地丘陵 → 平原狭小 → 人口高度集中在沿海平原；森林覆盖率高（约 70%）；**工业集中在太平洋沿岸和濑户内海沿岸**（便于进口原料、出口产品）；以黄种人为主。
- **俄罗斯**：海陆兼备，地跨亚欧两洲；**森林面积世界最大**（主要为亚寒带针叶林，即泰加林）；工业多分布在欧洲部分和资源丰富的地区；多民族国家，以白种人为主。
- **共同特征**：**森林资源丰富**（D 选项常考）。
- **日本工业沿海分布的原因**：岛国 → 缺乏矿产原料 → 需大量进口 → 沿海建港便于海运 → 工业布局在沿海。
- **俄罗斯工业靠近资源分布的原因**：国土辽阔 → 资源丰富 → 工业靠近原料产地 → 降低运输成本。

## 易混辨析

| 选项 | 为何错 |
|------|--------|
| 海陆兼备 | 日本是岛国，不具备典型"海陆兼备"特征；俄罗斯才是海陆兼备 |
| 白种人为主 | 日本以黄种人为主，俄罗斯以白种人为主，不能笼统说两国都是白种人 |
| 工业在内陆 | 日本工业在沿海，俄罗斯工业虽在内陆但靠近资源产地，不是简单"内陆" |
| 两国都是岛国 | 俄罗斯是世界上面积最大的国家，海陆兼备，绝不是岛国 |

## 考试技巧

- "两国共同特征"类题目 → 逐项排除法：用"日本是否满足？俄罗斯是否满足？"逐一验证每个选项。
- 比较两个国家时，建立对比表格：位置 → 地形 → 气候 → 资源 → 工业 → 人种 → 人口，逐项对比不容易遗漏。
- 题目涉及"森林"关键词 → 优先考虑日本（覆盖率）和俄罗斯（总面积）的共同点。
