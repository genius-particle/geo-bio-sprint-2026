# 地生冲刺 UI 重设计 · 设计 Spec

## 产品本质

八年级地理/生物会考备考的**个人局域网 Web 工具**。手机拍照录入错题 → 电脑端 Claude Code 技能分析 → 手机复习、查知识库、做练习。无登录、无云端 AI、移动端优先。

## 受众与场景

- **主用户**：八年级学生（单手操作、课间/在家复习）
- **辅助用户**：家长协助拍照录入
- **设备**：手机 390px 逻辑宽为主；Pad 横屏次要
- **情感基调**：温暖可信、不幼稚、降低考试焦虑、学科区分清晰

## 视口与交付

- 原型视口：**390×844**（iPhone 逻辑尺寸）
- 每套 HTML **平铺 5 屏**：首页 / 错题本 / 知识库 / 练习 / 题目详情
- 输出：`design/ui-redesign/design-demos/{a-journal,b-khan,c-naoto}.html`

| 学科 | 主色 | 用途 |
|------|------|------|
| 地理 | `#2563EB` | 徽章、筛选激活、读图相关强调 |
| 生物 | `#16A34A` | 徽章、筛选激活、概念相关强调 |
| 品牌 | 方向各异 | A 赤陶橙 / B 包豪斯蓝 / C 墨绿 `#1B4332` |

## 必保留功能位

1. 首页：统计（总录入/待分析/错题）、拍照 CTA、最近录入列表
2. 错题本：学科筛选 + 攻克中/已掌握 + 章节列表 + 复习次数
3. 知识库：知识点列表（B 版含搜索框）
4. 练习：学科筛选 + 会话列表或空态
5. 题目详情：状态徽章、学科、解析区占位

## 禁止项

- 紫色渐变 hero、装饰性 stock 图
- 编造统计数据
- Emoji 作主导航图标（原型与落地均改 SVG）

## 三套方向摘要

| 方向 | 逻辑 | 气质关键词 |
|------|------|-----------|
| A `a-journal.html` | 暖色出版物 Warm Editorial | 纸感、衬线标题、手账条目 |
| B `b-khan.html` | Khan Academy / 包豪斯几何 | 进度环、Segmented Control、搜索 |
| C `c-naoto.html` | 原研哉白盒画廊 | 极简留白、发丝分割、墨绿 accent |

## React 落地默认方向

用户未选型时，**方向 C（克制工具）** 与「个人工具、长期使用不疲劳」定位最契合，作为生产代码迁移基准。
